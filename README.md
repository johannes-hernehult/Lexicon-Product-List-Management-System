# Product List Management System

A console application for managing a list of products.

## Features

- Add products with a name, category, and price.
- View products sorted by price and see their total price.
- Search products by name or category (case-insensitive).
- Type `q` to:
  - Quit the main menu.
  - Cancel an input.
  - Exit a search.

## Data Storage

Products are kept in memory while the application is running. They are not saved after the application closes.
